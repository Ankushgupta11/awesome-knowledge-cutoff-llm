# Tools and Libraries

This file contains tools useful for researching knowledge cutoff effects and building literature-review systems.

## 1. Semantic Scholar

**Official site:** https://www.semanticscholar.org/

**API:** https://www.semanticscholar.org/product/api

**Purpose:** Scholarly search, paper metadata, author information, citations, and related-paper discovery.

**Relevance:** Useful for discovering and verifying papers and for building retrieval pipelines for literature-review systems.

---

## 2. OpenAlex

**Official site:** https://openalex.org/

**Documentation:** https://docs.openalex.org/

**Purpose:** Open scholarly metadata and citation graph covering works, authors, institutions, venues, and concepts.

**Relevance:** Useful for constructing large-scale and time-aware scholarly datasets.

---

## 3. Crossref

**Official site:** https://www.crossref.org/

**API:** https://api.crossref.org/

**Purpose:** DOI registration and scholarly metadata retrieval.

**Relevance:** Useful for verifying citation metadata generated by an LLM.

---

## 4. arXiv

**Official site:** https://arxiv.org/

**API documentation:** https://info.arxiv.org/help/api/index.html

**Purpose:** Scientific preprint discovery and access.

**Relevance:** Particularly useful for rapidly evolving fields because new research appears continuously.

---

## 5. Zotero

**Official site:** https://www.zotero.org/

**Purpose:** Reference management, bibliography organization, citation collection, tagging, and PDF/library management.

**Relevance:** Useful for organizing verified papers collected during a literature review.

---

## 6. LangChain

**Official site:** https://www.langchain.com/

**Documentation:** https://docs.langchain.com/

**Purpose:** Framework for building LLM applications involving retrieval, tools, agents, and document workflows.

**Relevance:** Can be used to prototype retrieval-augmented literature-review pipelines.

---

## 7. LlamaIndex

**Official site:** https://www.llamaindex.ai/

**Documentation:** https://docs.llamaindex.ai/

**Purpose:** Framework for connecting LLMs with external documents, indexes, retrieval systems, and data sources.

**Relevance:** Particularly useful for building document-grounded literature-review applications.

---

## 8. Hugging Face Transformers

**Official site:** https://huggingface.co/

**Documentation:** https://huggingface.co/docs/transformers/

**Purpose:** Open-source tools and pretrained models for NLP and machine learning.

**Relevance:** Useful for experimenting with language models, embeddings, rerankers, summarization models, and evaluation pipelines.

---

## 9. Pyserini

**GitHub:** https://github.com/castorini/pyserini

**Purpose:** Reproducible information-retrieval toolkit built around Lucene and related retrieval technologies.

**Relevance:** Useful for establishing strong retrieval baselines before comparing them with LLM-based retrieval.

---

## Recommended Tool Workflow

| Task | Recommended tools |
|---|---|
| Discover papers | Semantic Scholar, OpenAlex, arXiv |
| Verify metadata | Crossref, Semantic Scholar |
| Manage references | Zotero |
| Build retrieval system | Pyserini |
| Build RAG workflow | LangChain, LlamaIndex |
| Experiment with models | Hugging Face Transformers |

## Verification Principle

Tools should assist research rather than replace verification. A generated citation should be checked against an authoritative scholarly record before it is included in a final bibliography.
